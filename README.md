# Smart Building – Plateforme de monitoring et d'analyse de logs

Mini-projet IT Business School · Scénario B : Infrastructure IoT / Smart Building

Plateforme qui collecte, indexe, recherche et visualise les logs des capteurs d'un bâtiment intelligent, avec la stack ELK, MongoDB, Redis et une application web Flask, déployée avec Docker Compose.

## Installation

Les instructions de déploiement seront ajoutées avec le fichier docker-compose.yml.
